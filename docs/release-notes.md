# OopzGuard 0.1.0 实验版

为 Windows x64 的 Oopz 0.88.41 已调查快照提供同目录加载的 `dwmapi.dll`。默认处理两条广告请求路径、三个发现页广告字段，并过滤 Oopz 内已实现的 OBS 窗口查询。

## 兼容范围

- 只支持 `data/app.so` 大小为 31,851,424 字节、SHA-256 为 `8384ee1a0a3c39194755034328c34ec9dc1f76842d38144cc78b43c3153cc8aa` 的目标快照。版本号相同仍须满足文件校验。
- 2026-10-11 调查时官网安装包名称为 1.4.6.1；该版本及其他新版未适配、未验证。
- 版本不匹配或临时副本准备失败时，保留原快照与原窗口查询。

## 修改内容

广告处理仅在临时副本中等长修改五处 Dart 字符串，并更新字符串哈希：

| 原始字符串 | 临时副本字符串 |
| --- | --- |
| `/uni/advertisement/v1/list` | `/uni/advertisemenz/v1/list` |
| `/advertisement/v2` | `/advertisemenz/v2` |
| `advertisementBannerList` | `advertisemenzBannerList` |
| `adBanner` | `xxBanner` |
| `adSection` | `xxSection` |

路径改写使对应广告请求失败；字段改名使对应广告键不再读取。其他推广接口、失败处理或内存状态仍可能影响结果，不保证消除全部广告。

OBS 过滤仅覆盖该 Oopz 进程经 Flutter/Dart 动态解析到的 Win32 窗口查询，包括已实现的查找、枚举、标题及类名查询。当前识别 `obs.exe`、`obs32.exe`、`obs64.exe`、`yyobs.exe` 及 `obs-studio` 目录路径；不保证覆盖其他直播软件、改名后的软件或独立的进程枚举。OBS 可能因此不显示在 Oopz 的屏幕共享窗口列表中。

原始 `oopz.exe`、`flutter_windows.dll` 和 `data/app.so` 保持不变；系统 DWM 导出转发到系统库。关闭 Oopz 后移除添加的 DLL 即可回滚。

## 本地验证与限制

2026-10-11 的本地受控测试已经完成：

- 匹配快照修改、缓存复用、不同大小透传、同大小 SHA 不匹配透传、配置关闭透传等五个冷启动用例均为 0 failures；同进程的其他 AOT 路径保留原路径。
- 窗口过滤辅助测试为 0 failures；真实 Flutter 引擎通过六字段参数创建与销毁检查。
- 修改快照在真实引擎中读取到故意指定不存在的入口，出现入口不存在诊断。该测试没有调用 Oopz 主入口，伴随的根 isolate 错误是测试条件的结果。
- 原始 `app.so` 在测试后哈希未变化。

上述为本地验证记录，不代表 GitHub CI 已成功。尚未完成登录后广告位、主播模式、语音与屏幕共享的完整界面实测，也没有验证当前官网新版。公开网页逻辑与静态字符串证据不能等同于桌面运行效果。

安装、日志、开关与回滚步骤见发布包的 `使用说明.txt` 或仓库 [使用说明](使用说明.txt)。调查来源及详细证据见 [调查报告](../research/调查报告.md)。
