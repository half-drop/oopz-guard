OopzGuard v0.2.0 正式版
Guard 系列：Windows Oopz 自适应去广告与 OBS 窗口过滤工具

工作方式
Windows x64 Oopz，启动时自动识别广告请求、数据字段和素材地址。
不绑定客户端版本号、固定文件大小、文件指纹或补丁位置。
更新后的下次启动自动重新扫描，无需为普通版本更新重新编译。
未知结构或临时副本准备失败时使用原始快照；OBS 过滤独立工作。

安装
1. 解压完整 Windows 安装包，从系统托盘完全退出 Oopz。
2. 将 dwmapi.dll 放到 oopz.exe 同目录。
   常见路径为 %LOCALAPPDATA%\oopz；自定义安装以实际程序位置为准。
3. 用原来的 Oopz 快捷方式启动客户端，默认开启两项功能。
同目录已有 dwmapi.dll 时，先保留并确认用途，避免覆盖其他补丁。
DLL 应放在客户端目录，不要放入 Windows 系统目录。

查看状态
打开 %TEMP%\OopzGuard，查看最新 oopz-进程号.log。
Adaptive snapshot 显示广告请求、字段、素材的命中数量。
patched=0 表示未发现符合规则的内容。
SNAPSHOT_UNRECOGNIZED_OR_IO_ERROR 表示无法识别或准备副本，使用原始快照。
OBS 过滤状态会单独记录。BlockAds=0 表示按设置关闭广告处理。

功能与设置
在临时副本中等长改写广告字符串并更新 Dart 字符串哈希，保持对象布局。
自动适应文件位置、类编号、单字节/双字节编码和三种哈希布局变化。
覆盖明确广告请求、广告数据字段及广告目录素材，保留普通横幅与通用推荐。
OBS 过滤识别 obs.exe、obs32.exe、obs64.exe、yyobs.exe 及 obs-studio 路径。
OBS 可能不出现在 Oopz 的屏幕共享窗口列表中。
可选：将 oopz_guard.ini.example 复制为 DLL 同目录的 oopz_guard.ini：
[Guard]
BlockAds=1
HideOBSWindows=1
1 为开启，0 为关闭；默认无需配置文件。修改后完全退出并重启 Oopz。

客户端更新
下次启动自动扫描新快照；官方更新若移除了 DLL，重新放置即可。
框架结构彻底变化或广告命名改变仍可能需要更新规则。

卸载与回滚
完全退出 Oopz，移除添加的 dwmapi.dll；如创建过 oopz_guard.ini，也可删除。
原始 oopz.exe、flutter_windows.dll 与 data\app.so 不会被替换或修改。
关闭所有使用本 DLL 的进程后，可选删除 %TEMP%\OopzGuard 临时缓存。

验证范围
当前官网客户端静态命中 25 处：2 条请求、11 个字段、12 条素材地址。
真实引擎读取和跨结构回归通过，详细测试范围见 VALIDATION.md。
登录后的广告展示、语音和共享流程尚未完整人工验收。
本次构建记录见 build-info.json，下载附件校验见 SHA256SUMS.txt，
包内文件校验见 FILE_HASHES.txt；发行文件校验不限制客户端版本。
