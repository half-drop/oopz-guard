# 自适应广告过滤调查与实现

调查及验证日期：2026-10-12。v0.2.0 将旧版五处固定补丁改为启动时发现结构与广告内容，支持不同文件位置、类编号、编码和哈希布局，无客户端版本或 SHA 白名单。

## 官网版本核对

[官方 Windows 下载入口](https://www.oopz.cn/download/xx) 重定向到 [oopz_setup_v1.4.6.1.exe](https://downloadcdn.oopz.cn/release/146/oopz_setup_v1.4.6.1.exe)。只读解包外层 NSIS 与内层 `app.7z` 后，真正客户端 `data/flutter_assets/assets/version` 为 `0.88.41`，`data/app.so` 与本机快照完全相同。外层安装器自己的 `data/app.so` 属于安装界面，不能当作客户端分析。

安装包名与客户端内层版本不同，不能据安装包名认定未适配。旧调查报告中该项推断已更正。

## 为什么能够跨版本扫描

根据 [Dart 对象定义](https://github.com/dart-lang/sdk/blob/main/runtime/vm/raw_object.h)、[只读镜像序列化](https://github.com/dart-lang/sdk/blob/main/runtime/vm/image_snapshot.cc) 和 [Dart 哈希实现](https://github.com/dart-lang/sdk/blob/main/runtime/vm/hash.h)，字符串对象包含长度、类编号、对象大小与字符串哈希。实际扫描以这些互相校验的结构定位字符串，使用多对象一致性发现布局，不要求类编号固定为旧值。

- 读取 ELF64 x64 只读加载段，排除可执行代码与可写数据；验证范围与重叠。
- 校验长度、对齐、大小标签及 Dart 字符串哈希。
- 识别单字节/双字节字符串，尝试头部哈希、压缩独立哈希、非压缩独立哈希三种布局；每类布局至少有八个有效对象才能使用。
- 按广告特征定位内容，保持长度、类型和大小标签，等长改写并更新对应哈希。
- 对每次生成的副本计算内容标识用于缓存隔离与完整性检查；这不限制原始客户端文件。

文件读取上限 512 MiB 是内存分配边界，不是固定大小匹配。未识别结构使用原始快照。未来完全不同的对象格式、非 ELF AOT、Flutter 接口重大变化仍需维护。

## 广告覆盖策略

[官方网页客户端](https://web.oopz.cn/) 公开的 Dart 构建可见 `advs` 与 `AREA_ADV`、`LOGIN_ADV`、`SHOP_ADV` 模型，以及 `advertisementBannerList`、`adSection`、`adBanner` 等数据字段。请求失败不一定清空已有状态，因此本版同时处理广告请求和数据解析字段，并补充广告素材。

| 来源 | 处理方式 |
| --- | --- |
| API 路径 | 匹配独立广告路径段，不固定 `/v1`、`/v2` 或后缀 |
| 数据字段 | 匹配广告列表、横幅、分区及推荐广告字段，含 `advs` 和 `hotRecommendAdItem` |
| 素材 | 匹配 HTTP(S) 与 `assets/` 下的明确广告路径段 |

当前官网客户端命中 25 个对象：2 条 API、11 个字段、12 条素材。素材来自广告目录，包括默认及示例图片；并非 25 个独立广告位。广告特征宽化到明确的 `advertisement(s)`、`advert(s)`、`advertising`、`ads`、`ad` 路径段，但不改普通 `banner`、通用推荐、域名中的 `ads`、源码路径和业务方法名，以减少正常内容误伤。

这是一组跨版本特征规则，不是联网下载的动态规则库。未包含明确广告特征的新名称、动态拼接地址和新框架可能绕过现有规则。用户更新客户端后的首次启动会自动重新扫描；是否清除登录后所有广告需实际 UI 验证。

## OBS 与引擎

OBS 过滤独立于广告扫描，在 Dart FFI 查询处处理窗口 API。客户端广告结构未知时也按设置保持过滤。Flutter 参数使用 [官方 Windows 六字段定义](https://github.com/flutter/engine/blob/main/shell/platform/windows/public/flutter_windows.h)，仅替换临时副本路径。

测试范围及真实引擎读取证据见 [VALIDATION.md](../VALIDATION.md)。不分发官方快照或修改副本。
